# レシピ管理機能 詳細設計書

## 1. 機能概要
レシピの登録・編集・管理機能。AIが生成したレシピを含むすべてのレシピをユーザーが編集可能。材料はマスタ管理とする。画像はGCSに保存。

## 2. データモデル変更 (schema.md)
- `ingredients_master`テーブルを新設。
- `recipe_ingredients`テーブルの`name`を`ingredient_id` (SMALLINT) に変更。

## 3. API設計
- `GET /recipes`
    - レシピ一覧取得（検索・フィルタリング対応）
- `POST /recipes`
    - レシピ新規登録（画像アップロードを含む）
- `PATCH /recipes/{id}`
    - レシピ内容（タイトル、手順、材料、画像URL）の更新
- `GET /ingredients`
    - 材料マスタ一覧取得（検索用）

## 4. UI/UX設計
- **レシピ編集画面**:
    - タイトル、説明、画像アップロード項目。
    - 材料リストの動的追加・編集（材料マスタからの選択または新規作成）。
- **画像管理**:
    - フロントエンドでGCSへの署名付きURLを用いた直接アップロード、またはバックエンド経由でのアップロードを検討。

## 5. 外部連携
- **GCS (Google Cloud Storage)**: レシピ画像を保存。
- **AI連携**: AI生成レシピの場合、初期値として自動入力されるが、登録/保存後はユーザーが自由に編集可能。
