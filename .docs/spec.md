# プロジェクト仕様書 (Spec.md)

## 1. プロジェクト概要
家庭内での一週間の献立作成、および必要な買い物リストの自動生成・管理を行うアプリケーション。
GeminiなどのAIを活用し、冷蔵庫の在庫（余り物）や栄養バランスを考慮した献立提案・自動登録機能を備える。

### ターゲットユーザー
- 家庭で献立作成から買い物までを担当するユーザー。
- 家族間で献立情報を共有し、共同で買い物リストを管理したいユーザー。
- 在庫を効率的に管理し、食品ロスを減らしながら献立を考えたいユーザー。

## 2. 機能要件

### 2.1 献立管理
- **週間カレンダー**: 1週間単位で朝・昼・夕の献立を設定できる。
- **レシピ選択**: 登録済みのレシピから献立を選択できる。
- **過去の献立の再利用**: 過去の特定の週の献立をコピーして現在の週に適用できる。

### 2.2 買い物リスト管理
- **自動生成**: 設定された献立に必要な材料を抽出し、買い物リストを自動生成する。
- **手動追加**: 献立に関係ない日用品などを手動でリストに追加できる。
- **カテゴリ分類**: 野菜、肉、魚、調味料などのカテゴリ別にリストを自動ソートする。
- **チェックリスト機能**: 買い物中に購入済みアイテムをチェック。
- **在庫への反映**: 買い物リストでチェック（購入完了）したアイテムは、自動的に「在庫管理」へ追加される。

### 2.3 レシピ管理
- **レシピ登録**: 材料、分量、工程、画像を登録できる。
- **画像保存**: レシピに関連する画像をアップロードし、永続化する。
- **AI生成レシピの保存**: AIが提案した新しいメニューを自動でデータベースへ登録する。

### 2.4 家族共有
- **共有アカウント/グループ**: 同一家族内でデータを共有し、複数端末から同時に閲覧・編集できる。
- **共同編集**: 誰かが買い物リストや在庫を更新すると、リアルタイムに他のメンバーに反映される。

### 2.5 AIアシスタント機能 (AI Meal Planner)
- **献立生成リクエスト**:
    - **在庫活用**: 「在庫管理」にある食材を優先的に消費する献立を依頼できる。
    - **バランス指定**: 「低糖質」「高タンパク」「子供向け」などのテーマ指定。
- **提案と反映フロー**:
    - **プレビュー**: AIが生成した献立案をカレンダー形式で確認。
    - **一括採用**: 「この献立を採用」ボタンにより、カレンダーへ一括登録。
- **レシピ自動連携**: AI提案メニューが未登録の場合、材料・作り方を自動生成しレシピ管理に登録。

### 2.6 在庫管理機能 (Inventory Management)
- **在庫一覧**: 冷蔵庫、冷凍庫、常温保存などの場所別にアイテムを管理。
- **在庫の増減**:
    - **手動調整**: 直接数量を変更可能。
    - **調理による消費**: 献立に従って調理を完了した際、使用した材料を在庫から減算（確認ダイアログを表示）。
- **期限管理**: 賞味期限が近いものをアラート表示し、AI献立提案時に優先消費対象とする。

## 3. 非機能要件
- **モバイルファースト**: 買い物中やキッチンでの操作に適したUI。
- **オフライン閲覧**: 通信が不安定な場所でも、最後に同期した買い物リスト・在庫を確認できる。
- **外部API連携**: Gemini API等の大規模言語モデルとの連携。

## 4. 技術スタック
（省略：Vue.js, Go, PostgreSQL, Tailwind CSS等）

## 5. データモデル案（主要エンティティ）
- **User / Household**: ユーザー・家族グループ。
- **Recipe**: レシピ情報（AI生成フラグ等）。
- **Ingredient**: レシピに含まれる材料と分量。
- **Inventory**: 在庫アイテム（名前、数量、単位、賞味期限、保管場所）。
- **MealPlan**: カレンダー情報。
- **ShoppingListItem**: 買い物リスト（アイテム名、数量、カテゴリ、購入済みフラグ）。
