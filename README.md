# MenuPlanner

家庭内での一週間の献立作成と、それに必要な買い物メモを効率的に管理するためのアプリケーションです。

## 📋 プロジェクト概要

「何を作るか迷う」「冷蔵庫の在庫を腐らせてしまう」「買い忘れが発生する」といった家庭内の悩みを解決します。
AI（Gemini）を活用した献立提案や、献立から自動生成される買い物リスト、家族間でのリアルタイム共有機能を備えています。

### 主な機能
- **献立管理**: 1週間単位のカレンダー形式で3食の献立を管理。
- **買い物リスト**: 献立に必要な材料を自動抽出。カテゴリ別のチェックリスト機能。
- **在庫管理**: 冷蔵庫・冷凍庫・常温の在庫を管理。賞味期限アラート機能。
- **レシピ管理**: 自作レシピやAI提案レシピの保存・編集。
- **家族共有**: 同一世帯内でのデータ同期と共同編集。
- **AIアシスタント**: 在庫を考慮した献立提案とレシピ生成。

## 🛠 技術スタック

### バックエンド
- **言語**: Go
- **フレームワーク**: Gin
- **データベース**: PostgreSQL (pgx v5)
- **テスト**: testing, testify/assert

### フロントエンド
- **フレームワーク**: Vue 3 (Composition API / `<script setup>`)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **ビルドツール**: Vite

## 🚀 開発ガイドライン

本プロジェクトでは **TDD (テスト駆動開発)** を必須としています。

1. **Red**: 機能を実装する前に、期待する動作を定義したテストコードを書く。
2. **Green**: テストをパスさせるための最小限の実装を行う。
3. **Refactor**: グリーン状態を維持したまま、コードの品質を向上させる。

### コミットメッセージ規約
`機能名｜prefix: 対応内容` の形式で記述してください。

- `add`: 新機能・ファイルの追加
- `fix`: バグ修正
- `update`: 機能改善・仕様変更
- `refactor`: コード整理
- `docs`: ドキュメント関連

例: `家族共有｜add: 招待コード発行機能のテストと実装`

## ⚙️ セットアップ（開発中）

### バックエンド
```bash
cd backend
go mod download
# DATABASE_URL 環境変数を設定して実行
go run cmd/api/main.go
```

### フロントエンド
```bash
cd frontend
npm install
npm run dev
```
